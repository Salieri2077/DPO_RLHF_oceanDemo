# Qwen3-1.7B Ocean GRPO（2026-10-08 ~ 10-09）

起点是 [Qwen3-1.7B Ocean SFT](../SFT%20Evaluation/QWEN3_1.7B_SFT.md)。开训前做了 best-of-8 检查：采样均分 1.67，best-of-8 为 2.43，greedy 为 2.28，组内有明显好坏差异，可以开 GRPO。预期是采样回答变好、编造变少，greedy 提升有限。

## 设置

| 项 | 取值 |
|---|---|
| 策略 / 参考 | SFT LoRA 合并进 Base（`scripts/merge_qwen_lora.py`），再加新的 LoRA r32 / α64 训练；参考模型为同一合并模型关闭 LoRA |
| 训练题 | `ocean_sft_val` 中 SFT 未训练过的题（去掉前 512 条和 GRPO 验证集 200 条，去重），约 4.4K 题 |
| 采样 | 每题 8 个，T=0.8，最长 1024 新 token（不截断），每步 4 卡 × 1 题 |
| 奖励 | Qwen2.5-72B-Instruct 对 8 个候选一次打分，顺序随机打乱；组内标准差 < 0.25 的组不更新；不加长度、重复奖励 |
| 目标 | on-policy GRPO（一次 rollout 一次更新），组内标准化优势，KL(k3) β=0.04，按 token 归一 |
| 超参 | 200 步，LR 1e-5，10 步 warmup，余弦到 10%，梯度裁剪 1.0 |
| 代码 | `trainer/train_grpo_hf.py`，评估 `GRPO Evaluation/evaluate_qwen_grpo.py`，串联 `scripts/run_qwen_grpo_chain.sh` |
| SwanLab | OceanHeart-GRPO / `qwen3-1.7b-ocean-grpo-q72b-20261008-2318` |

中断与续训：第 19～30 步 SiliconFlow 对 72B 返回 429 限流（约 7 RPM、2.5 万 TPM），累计 13 组失败后程序保存状态退出。之后给 429 加了 10～60 s 抖动退避（最多 8 次），从第 30 步续训到同一 SwanLab run。续训后又被限流 192 次，全部通过等待恢复，只多失败 2 组。失败组只跳过，不使用伪奖励。

## 训练曲线

| 步数 | 训练奖励（每步新题） | KL | 有效组比例 | 回答 token | 每步秒数 |
|---|---:|---:|---:|---:|---:|
| 1–25 | 1.61 | 5e-5 | 65% | 360 | 35 |
| 26–50 | 1.71 | 2.5e-4 | 67% | 380 | 39 |
| 51–100 | 1.93 | 1.2e-3 | 66% | 381 | 48 |
| 101–150 | 1.92 | 2.7e-3 | 64% | 377 | 47 |
| 151–200 | 1.98 | 4.0e-3 | 65% | 382 | 49 |

验证集（16 题 × 4 采样，训练裁判 Qwen2.5-72B）：第 0 步 1.81 → 第 25 步 1.73 → 第 50 步 1.85 → 第 75 步 1.73 → 第 100 步 2.09 → 第 125 步 2.08 → 第 150 步 2.05 → 第 175 步 2.21 → 第 200 步 **2.33**。

- KL 在第 100 步后进入 1e-3～1e-2 的目标区间，没有失控。
- 回答长度稳定在 360～380 token，没有出现靠变长讨好裁判的现象。正常结束率仍接近 100%。
- 到第 200 步验证奖励仍在上升，尚未收敛。

## 独立裁判配对评估

SFT 测试集前 100 题。SFT 与 GRPO 各生成 1 个 greedy 和 2 个 T=0.8 采样，6 个候选同一请求，由 DeepSeek-V3（与训练裁判不同）正反序各打一次取平均。

| 指标 | SFT | GRPO | GRPO − SFT（95% bootstrap） | 胜 / 负 / 平 |
|---|---:|---:|---|---|
| 采样回答均分 | 1.15 | **1.32** | **+0.17 [+0.02, +0.33]** | 49 / 31 / 20 |
| 每题最差采样 | 0.59 | **0.80** | **+0.21 [+0.01, +0.42]** | 41 / 28 / 31 |
| greedy | 1.52 | 1.64 | +0.12 [−0.11, +0.35]（不显著） | 31 / 16 / 53 |
| ≤ −1 分的回答占比 | 17% | 14% | | |
| 正常结束率 | 100% | 99.3% | | |
| 平均 token | 341 | 348 | | |

分语言：英文 51 题采样 1.20 → 1.45，greedy 1.63 → 1.77；中文 49 题采样 1.10 → 1.18，greedy 1.41 → 1.50。

行为变化，按 300 个回答统计：
- 每千字的数字个数 5.60 → 4.89（−13%），具体数值更少，与"编造变少"一致。
- 每千字的不确定表述（可能、通常、may、likely 等）1.43 → 1.68（+17%）。
- 长度只增加 4%。

裁判噪声：600 个候选中 64 个正反序相差 > 1 分（10.7%）。同一 SFT 模型在本次评估中 greedy 得 1.52，在 SFT 三模型评估中得 1.61。裁判分随同组候选而变，只能在同一评估内比较。

## 结论

1. **结果与开训前的预期一致。** 独立裁判下，GRPO 显著提高了采样回答均分（+0.17）和每题最差回答（+0.21），低分回答减少。greedy 方向为正但不显著，与 best-of-8 检查显示的 greedy 余量小相符。
2. **没有发现明显的奖励投机。** 长度没有膨胀，独立裁判也确认了提升。不过训练裁判看到的提升（+0.52）大于独立裁判（+0.17）：一部分可能是 16 题验证集的噪声，一部分可能是对训练裁判偏好的拟合。
3. **机制解释。** 模型少写具体数字、多用限定语，减少了自信编造，这正是 SFT 阶段发现的主要问题。英文提升大于中文。
4. **尚未收敛。** 验证奖励和 KL 仍在上升，可以继续训练或适当提高学习率。
